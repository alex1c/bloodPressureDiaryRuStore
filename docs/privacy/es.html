Política de privacidad

Aplicación «Diario de presión arterial» / «Дневник давления» (com.calculatorplatform.bpdiary)
Fecha de entrada en vigor: 6 de octubre de 2026

RU EN ES DE

1. Información general

Esta aplicación es un diario personal para registrar la presión arterial, el pulso y otras métricas de salud que usted introduce. No es un dispositivo médico, no diagnostica y no sustituye la consulta médica.

2. Datos que usted introduce

  • presión arterial (sistólica y diastólica);
  • pulso;
  • notas y etiquetas;
  • métricas de salud (peso, glucosa, SpO₂, temperatura);
  • medicamentos, horarios y tomas registradas;
  • nombres de perfiles familiares;
  • idioma y recordatorios;
  • copias de seguridad creadas manualmente.

3. Dónde se almacenan

Los datos principales del diario se guardan localmente en el dispositivo en una base SQLite. No hay sincronización con un servidor del desarrollador ni cuentas de usuario en la nube del desarrollador.

4. Android Auto Backup

La copia de seguridad automática de Android (Auto Backup) está desactivada para los datos de esta aplicación. El método admitido es una exportación JSON manual desde Ajustes.

5. Perfiles

Los nombres de perfil permanecen en su dispositivo.

6. Copia JSON

Las copias se crean solo por acción explícita del usuario y no se suben a un servidor del desarrollador.

7. Informe PDF

El PDF se genera en el dispositivo y solo se comparte si usted usa la hoja de compartir del sistema.

8. Notificaciones

Se usan notificaciones locales de recordatorio. No hay push remoto del desarrollador.

9. Eliminación de datos

Puede eliminar mediciones, métricas, medicamentos, recordatorios y perfiles (excepto el último) dentro de la aplicación. No hay cuentas ni base de salud alojada por el desarrollador.

10. Analítica AppMetrica

Se usa Yandex AppMetrica para analítica técnica. No se envían valores de presión, pulso, medicamentos, notas ni nombres de perfil.

11. Publicidad e Advertising ID

Se usa Yandex Mobile Ads. El SDK puede tratar información técnica del dispositivo y el Advertising ID según las políticas de Yandex y la configuración del dispositivo.

12. Internet

Internet se usa para anuncios y eventos de AppMetrica. El diario funciona sin conexión permanente.
