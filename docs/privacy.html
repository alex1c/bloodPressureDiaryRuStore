Политика конфиденциальности

Приложение «Дневник давления» (com.calculatorplatform.bpdiary)
Дата вступления в силу: 2 сентября 2026 г.

1. Общие положения

«Дневник давления» — мобильное приложение для ведения личного дневника артериального давления, пульса и связанных показателей здоровья. Разработчик уважает конфиденциальность пользователей и описывает ниже, как обрабатываются данные.

2. Какие данные вы вводите в приложении

Пользователь может сохранять локально на устройстве:

  • артериальное давление (систолическое и диастолическое);
  • пульс;
  • заметки и теги к измерениям;
  • показатели здоровья (вес, глюкоза, сатурация, температура);
  • сведения о лекарствах и расписании приёма;
  • имена семейных профилей;
  • данные резервных копий, которые вы создаёте вручную.

3. Где хранятся данные

Основные пользовательские health-данные хранятся локально на устройстве пользователя в базе SQLite внутри приложения.

У приложения нет собственного сервера, облачного аккаунта разработчика и централизованной базы пользовательских записей. Разработчик не получает доступ к вашим измерениям, заметкам, лекарствам или профилям через серверную синхронизацию.

4. Профили

Имена семейных профилей хранятся только на вашем устройстве и используются для разделения записей внутри приложения.

5. Резервная копия

Резервная копия создаётся только по явному действию пользователя в разделе «Настройки». Файл JSON передаётся через системный Android Share Sheet или выбирается через системный document picker при восстановлении.

Приложение самостоятельно не загружает резервную копию на сервер разработчика.

6. PDF-отчёт для врача

PDF формируется локально на устройстве. Передача файла возможна только по вашему явному действию через Android Share Sheet (например, в мессенджер или почтовое приложение).

7. Уведомления

Приложение использует локальные уведомления для напоминаний о приёме лекарств. Удалённые push-уведомления от сервера разработчика не используются.

8. Аналитика AppMetrica

Для технической аналитики использования приложения подключён сервис Yandex AppMetrica.

Приложение не отправляет в аналитику конкретные значения:

  • давления и пульса;
  • веса, глюкозы, сатурации, температуры;
  • названий лекарств и дозировок;
  • заметок и имён профилей.

События аналитики содержат только обезличенные технические факты использования функций (например, что измерение было создано, без числовых значений).

9. Реклама

В приложении используется Yandex Mobile Ads / Рекламная сеть Яндекса. SDK может обрабатывать техническую информацию об устройстве и рекламный идентификатор в соответствии с политиками Яндекса.

10. Интернет

Доступ в интернет используется для:

  • загрузки и показа рекламы;
  • отправки обезличенных событий AppMetrica.

Основной дневник измерений, графики, лекарства и резервные копии работают локально и не требуют постоянного подключения к интернету.
